## 4. 🔬 Phát hiện Kỹ thuật Quan trọng

### 4.1 KVQuantMode Enum (vllm/v1/kv_cache_interface.py)

```python
class KVQuantMode(IntEnum):
    NONE = 0                    # BF16/FP16 (default) — 12 KB/token
    FP8_PER_TENSOR = 1          # --kv-cache-dtype fp8 (STT 17/61 THẤT BẠI — TPOT tăng lên 63ms)
    INT8_PER_TOKEN_HEAD = 2     # --kv-cache-dtype int8_per_token_head — 6 KB/token
    FP8_PER_TOKEN_HEAD = 3      # --kv-cache-dtype fp8_per_token_head — 6 KB/token (KHÁC fp8 cũ!)
    INT4_PER_TOKEN_HEAD = 4     # --kv-cache-dtype int4_per_token_head — 3 KB/token 🔥
    NVFP4 = 5                   # --kv-cache-dtype nvfp4 — Blackwell only ❌
```

### 4.2 Tại sao fp8 cũ (STT 17/61) thất bại nhưng INT4 mới có thể thành công

| Tiêu chí       | FP8 per-tensor (cũ)                    | INT4 per-token-head (mới)             |
| :------------- | :------------------------------------- | :------------------------------------ |
| Mode           | `FP8_PER_TENSOR` (1)                   | `INT4_PER_TOKEN_HEAD` (4)             |
| Scaling        | Per-tensor → tính scale toàn bộ tensor | Per-token-head → scale nhỏ gọn, fused |
| KV size        | 6 KB/token                             | **3 KB/token**                        |
| Bandwidth gain | 2x                                     | **4x**                                |
| Kernel path    | Cũ, overhead Python wrapper            | Mới, fused vào attention kernel       |
| TPOT kết quả   | 63ms (TỆ HƠN baseline!)                | ~19ms (lý thuyết)                     |
