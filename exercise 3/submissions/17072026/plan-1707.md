# Kế hoạch tối ưu hóa LFM2.5 - Ngày 17/07/2026

## 1. PHÂN TÍCH KẾT QUẢ NGÀY 16/07 & ĐỊNH HƯỚNG MỚI

Ngày 16/07 chúng ta đã hoàn thành quét toàn bộ 15 slots và phát hiện ra các kết quả cực kỳ quan trọng:
1. **Lượng tử hóa FP8 (Slot 15/2210) là bước ngoặt quyết định**: Điểm số nhảy vọt từ **43-45 điểm** lên thẳng **55.04 điểm**. Đây là lần đầu tiên TPOT Median hạ từ 5ms xuống **4ms**, TTFT P50 giảm xuống **79ms**, và TTFT P95 giảm xuống **115ms**.
2. **Chunked Prefill (Slot 8/2133) hiệu quả rất cao**: Trong môi trường FP16, bật Chunked Prefill với `max-num-batched-tokens=4096` giúp tăng điểm từ 43.08 lên **45.08** (+2 điểm), nhờ triệt tiêu trễ prefill chèn ngang.
3. **Số luồng CPU OMP_NUM_THREADS=2 (Slot 10/2146)**: Đạt **44.54 điểm** (so với 43.08 ở OMP=4), chứng minh việc hạ luồng CPU giúp giảm tranh chấp và context switching trên 3 cores vật lý của Node.
4. **Hạ max-model-len=8192 (Slot 14/2209)**: Giúp cải thiện nhẹ lên **43.62** nhờ giảm tải KV Cache manager.

**Chiến lược Ngày 17/07/2026**:
Xây dựng toàn bộ các thử nghiệm trên nền tảng **FP8 Golden Baseline** nhằm kết hợp các nhân tố tối ưu này lại với nhau để bứt phá điểm số tối đa (kỳ vọng vượt mốc 58+ điểm).

## 2. GOLDEN BASELINE CONFIG (Dùng chung cho ngày 17/07)

Mọi file docker-compose trong ngày hôm nay sẽ kế thừa cấu hình nền tảng lượng tử hóa FP8 dưới đây:

```yaml
services:
  model:
    image: vllm/vllm-openai:v0.22.1
    environment:
      - OMP_NUM_THREADS=4 # Sẽ được quét ở các slot sau
    entrypoint:
      - python3
      - -m
      - vllm.entrypoints.openai.api_server
    command:
      - --model=/model
      - --served-model-name=LFM2.5-1.2B-Instruct
      - --host=0.0.0.0
      - --port=8000
      - --max-model-len=32768 # Sẽ được quét ở các slot sau
      - --gpu-memory-utilization=0.95
      - --tensor-parallel-size=1
      - --enable-prefix-caching
      - --quantization=fp8 # Lượng tử hóa FP8 Online
      - --no-enable-log-requests
      - --disable-log-stats
      - --max-num-seqs=32 # Sẽ được quét ở các slot sau
    ports:
      - "8000:8000"
    shm_size: "2g"
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
```

## 3. CHI TIẾT 15 SLOTS THỬ NGHIỆM CHO NGÀY 17/07

Do giới hạn thời gian nộp bài cuối ngày, chúng ta sẽ thiết kế kế hoạch quét theo nhóm để người dùng có thể **nộp song song** từng nhóm slots.

### Nhóm 1: Quét Concurrency (Seqs Tuning) trên FP8 (Slot 1 - 4)
*Mục tiêu: Tìm `BEST_SEQS_FP8` tối ưu trễ xếp hàng hàng đợi khi mô hình đã chạy cực nhanh với FP8.*

| Tên Slot | Tên file compose | Cấu hình thay đổi | Mục tiêu / Kỳ vọng |
| :---: | :--- | :--- | :--- |
| **Slot 1** | `slot1-docker-compose.yml` | FP8 Base + `OMP=4` + `Seqs=32` | **Golden Baseline** (Đối chứng mốc 55.04 điểm). |
| **Slot 2** | `slot2-docker-compose.yml` | FP8 Base + `OMP=4` + `Seqs=48` | Thử nghiệm tăng concurrency lên 48 xem FP8 xử lý song song tốt hơn không. |
| **Slot 3** | `slot3-docker-compose.yml` | FP8 Base + `OMP=4` + `Seqs=24` | Thử nghiệm hạ concurrency xuống 24 để giảm tải scheduler. |
| **Slot 4** | `slot4-docker-compose.yml` | FP8 Base + `OMP=4` + `Seqs=16` | Thử nghiệm hạ concurrency cực hạn xuống 16 (giống mốc tối ưu ở FP16). |

### Nhóm 2: Quét Chunked Prefill trên FP8 (Slot 5 - 9)
*Mục tiêu: Đánh giá xem Chunked Prefill có hoạt động tốt trên FP8 không và tìm `BEST_CHUNK_FP8`. Mặc định dùng Seqs=32 làm mốc quét.*

| Tên Slot | Tên file compose | Cấu hình thay đổi | Mục tiêu / Kỳ vọng |
| :---: | :--- | :--- | :--- |
| **Slot 5** | `slot5-docker-compose.yml` | FP8 Base + `Seqs=32` + `--enable-chunked-prefill` | Chỉ bật Chunked Prefill mặc định của vLLM. |
| **Slot 6** | `slot6-docker-compose.yml` | `Slot 5` + `--max-num-batched-tokens=1024` | Chunk size nhỏ 1024. |
| **Slot 7** | `slot7-docker-compose.yml` | `Slot 5` + `--max-num-batched-tokens=2048` | Chunk size trung bình 2048. |
| **Slot 8** | `slot8-docker-compose.yml` | `Slot 5` + `--max-num-batched-tokens=4096` | Chunk size lớn 4096 (mốc tối ưu ở FP16). |
| **Slot 9** | `slot9-docker-compose.yml` | `Slot 5` + `--max-num-batched-tokens=8192` | Chunk size cực đại 8192. |

### Nhóm 3: Quét OMP Threads & Max Model Len trên FP8 (Slot 10 - 13)
*Mục tiêu: Kiểm chứng luồng CPU và dung lượng block memory tối ưu cho FP8.*

| Tên Slot | Tên file compose | Cấu hình thay đổi | Mục tiêu / Kỳ vọng |
| :---: | :--- | :--- | :--- |

| **Slot 11** | `slot11-docker-compose.yml` | FP8 Base + `Seqs=32` + `OMP_NUM_THREADS=3` | Khớp chính xác 3 cores vật lý của Node. |
| **Slot 12** | `slot12-docker-compose.yml` | FP8 Base + `Seqs=32` + `--max-model-len=16384` | Hạ giới hạn context tối đa về 16K. |
