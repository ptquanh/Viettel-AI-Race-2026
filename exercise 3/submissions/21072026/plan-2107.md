## 1. 🎯 MỤC TIÊU CHIẾN LƯỢC

Dựa trên phân tích 75 slots trước đó, **TPOT (4ms) là giới hạn vật lý** tại thiết lập hiện tại.
Để vượt ngưỡng 4ms, chúng bản cần khai thác lỗ hổng lớn nhất chưa từng được thử: **CUDA Graph Optimization**.

**Vấn đề cũ**: Script `python3_hijack` ở các version trước (v7, v8) đã block việc truyền JSON config cho `--compilation-config`, khóa cứng ở `{"mode": 3}` (FULL_AND_PIECEWISE mặc định).
**Giải pháp**: Xây dựng **Image v9** với script `python3_hijack` linh hoạt, cho phép truyền các biến môi trường:

- `VLLM_CUDAGRAPH_MODE`
- `VLLM_CUDAGRAPH_CAPTURE_SIZES`
- `VLLM_CUDAGRAPH_NUM_OF_WARMUPS`
