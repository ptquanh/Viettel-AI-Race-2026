## 2. Kết quả Slot 01 & Bài học — CON ĐƯỜNG INT4 ĐÃ CHẾT

### ❌ Slot 01: `bitsandbytes` NF4 (29.71đ, TPOT=14ms)

| Chỉ số        | Giá trị | So với baseline    |
| ------------- | ------: | ------------------ |
| ERS           |   29.71 | -31.53đ (thảm họa) |
| TPOT Median   |   14 ms | +10ms (×3.5 lần)   |
| TTFT P50      |   94 ms | +50ms              |
| TTFT P95      |  132 ms | +58ms              |
| Failed count  |       9 | +5                 |
| Accuracy drop |      0% | Không đổi          |

**Nguyên nhân**: `bitsandbytes` thực hiện runtime dequantization (INT4→FP16) trên CUDA cores **trước mỗi phép GEMM**. Chi phí tính toán giải nén này (~10ms) vượt xa tiết kiệm bandwidth (~0.9ms), khiến tổng TPOT tăng vọt lên 14ms.

**Bài học sâu**: INT4 runtime quantization chỉ có lợi khi:

- Model cực lớn (70B+) với weight read time chiếm >80% decode time
- Dequantization kernel tối ưu song song (bitsandbytes dùng kernel generic, không chuyên cho MIG)
- Trên model 1.2B nhỏ, dequantization overhead >> bandwidth savings

**Quyết định**: **LOẠI BỎ VĨNH VIỄN** nhánh bitsandbytes/INT4. Không dành thêm bất kỳ slot nào.

### Con đường còn lại duy nhất phá TPOT=4ms

Sau khi loại INT4 và Speculative, chỉ còn **2 khả năng lý thuyết** để hạ TPOT:

#### Khả năng 1: Overhead Reduction (~0.5-1ms tiết kiệm → TPOT 3-3.5ms)

- **CUDA Graph capture tối ưu hơn**: Giảm capture sizes, giảm warmup rounds
- **Compilation level tuning**: Level 2 vs 3, torch.compile mode
- **Memory allocator tuning**: `expandable_segments`, `PYTORCH_CUDA_ALLOC_CONF`
- **Scheduler tuning**: `VLLM_MAX_NUM_SEQS`, `VLLM_BLOCK_SIZE`
- Kỳ vọng: Nếu overhead giảm từ 2ms → 1-1.5ms, TPOT từ 4ms → 3-3.5ms

#### Khả năng 2: Deep Kernel Fusion cho GEMM epilogue (~0.3-0.5ms)

- Fuse RMSNorm + residual_add giữa các layer (tiết kiệm 2 kernel launch + 2 HBM reads/writes mỗi layer)
- 24 layers × 2 RMSNorm × ~4KB activation = ~192KB/layer, ~4.6MB tổng
- Tiết kiệm ~0.01ms bandwidth + ~0.5ms launch overhead (nếu CUDA graph chưa bắt)
- **Rủi ro**: CUDA Graph đã amortize launch overhead → benefit gần bằng 0
