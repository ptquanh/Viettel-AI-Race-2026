## 1. PHÂN TÍCH TOÁN HỌC: TRẦN ĐIỂM VỚI TPOT=4MS

### Công thức tính điểm (từ Spec BTC)

```
Score = 100 × ERS
ERS = (1/420) × Σ S_request
S_request = 0.5 × s_ttft + 0.5 × s_tpot

s_ttft = [clamp((400 - TTFT) / 390, 0, 1)]²
s_tpot = [clamp((10 - TPOT) / 9, 0, 1)]²
```

### Phân tích cố định TPOT = 4ms

| TPOT (ms) |  s_tpot   | Đóng góp điểm (×0.5) |
| :-------: | :-------: | :------------------: |
|   **4**   | **0.444** |      **0.222**       |
|     3     |   0.605   |        0.302         |
|     2     |   0.790   |        0.395         |
| 1 (floor) |   1.000   |        0.500         |

**s_tpot ở 4ms = 0.444** → Mỗi request chỉ đóng góp tối đa **0.222 điểm** từ TPOT.
