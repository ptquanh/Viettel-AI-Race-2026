## 1. PHÂN TÍCH TOÁN HỌC & CHIẾN LƯỢC QUYẾT ĐỊNH

### 1.1 Tại sao FP8 (Image v14) bị trần ở ~64 điểm?

- **Băng thông H200 MIG (18GB)**: ~0.65 TB/s.
- **Model 1.2B FP8**: Weight = 1.2 GB.
- **Weight read time / token**: `1.2 GB / 0.65 TB/s = 1.85ms`.
- **Compute + Kernel overhead**: ~2.0ms.
- **TPOT thực tế**: `1.85ms + 2.0ms = 3.85ms` → Grader BTC báo **4ms**.
- **Score Max với TPOT 4ms**: $S_{tpot} = ((10-4)/9)^2 = 0.4444$. Kể cả khi TTFT P50 = 40ms ($S_{ttft} = 0.852$), Score chỉ đạt $\approx 64.8$ điểm.

### 1.2 Con đường DUY NHẤT chạm mốc 70 điểm — Image v15 (Online INT4)

```
Weight INT4 = 0.6 GB
Weight read time = 0.6 GB / 0.65 TB/s = 0.92ms
TPOT thực tế = 0.92ms + 2.0ms = 2.92ms → Grader BTC báo 3ms!
S_tpot (3ms) = ((10-3)/9)² = 0.6049
S_ttft (47ms) = ((400-47)/390)² = 0.8198
Total Score = 100 × (0.5 × 0.8198 + 0.5 × 0.6049) = 71.2đ 🎯 (VƯỢT 70 ĐIỂM!)
```
