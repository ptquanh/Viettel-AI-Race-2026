## 1. NGUYÊN LÝ ĐỘT PHÁ TPOT: MEGA KERNEL FUSION (`v17`)

### Phân tích điểm nghẽn của `v16.3`:

Trong cấu trúc ShortConv Layer hiện tại của mô hình LFM2.5:

```python
# Luồng chạy nguyên bản (3 lần đẩy data ra/vào VRAM GPU):
BCx, _ = self.in_proj(hidden_states)     # 1. Linear Projection (Ghi BCx vào VRAM)
y = ShortConv.forward_cuda(...)          # 2. Fused ShortConv (Đọc BCx, Ghi y vào VRAM)
output, _ = self.out_proj(y)             # 3. Linear Out Projection (Đọc y, Ghi output vào VRAM)
```

Mỗi token decode phải trải qua **3 Kernel Launches liên tiếp** per layer (x24 layers = 72 kernel launches per token) và 2 lần đọc/ghi trung gian ra VRAM.
Dù `ShortConv` đã được fuse bằng C++, 2 phép tính Linear xung quanh vẫn làm tốn GPU Memory Bandwidth.

### Giải pháp Mega Fusion (`v17`):

Tạo một Custom CUDA Kernel tổng hợp: **`fused_lfm_block_decode`**:

- Thực hiện `in_proj + short_conv_update + out_proj` **trong cùng 1 CUDA Block / Thread Group** trên SRAM/Registers của GPU.
- Không ghi `BCx` hay `y` ra VRAM nữa! Dữ liệu được truyền trực tiếp qua Register/Shared Memory.
- Tiết kiệm **>60% băng thông GPU VRAM** per token decode -> Ép TPOT xuống **< 2ms**!
